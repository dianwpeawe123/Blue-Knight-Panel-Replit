# Running on Replit

- The editor workflow runs `BK_DATA_DIR=/tmp/blue-knight-preview-data PORT=5000 npm start`.
- Open `/knight` to access the panel. On first visit, create a panel password of at least 8 characters.
- Publishing is configured for a Reserved VM and runs `node index.js`.
- See `README.md` for optional publishing secrets and settings that can keep panel credentials and generated configuration stable across publishes.
